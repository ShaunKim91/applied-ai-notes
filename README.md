# AI Engineering Curriculum — Notes & Concepts

Original lesson notes and runnable concept notebooks covering six weeks of applied AI/ML topics — computer vision, LLM internals, multimodal document AI, RAG, and agentic AI (ReAct agents, safety guardrails, and framework-based agents with memory via LangChain).

Each week follows the same shape: a short README, 4 days of concise lesson notes, and one consolidated Jupyter notebook with runnable code for all 4 days.

| Unit | Topic |
|---|---|
| [1st_week](1st_week/) | Computer Vision Basics & Time Series (CNNs vs. ViT, diffusion image generation, decomposition & forecasting) |
| [2nd_week](2nd_week/) | LLM Internals, Audio AI & Sandboxing (tokenization/attention/KV cache, bi- vs. cross-encoders, ASR/TTS, code-execution isolation) |
| [3rd_week](3rd_week/) | Multimodal Document AI (vision-language extraction, structured JSON, PDF summarization, HTML table parsing) |
| [4th_week](4th_week/) | RAG Fundamentals (LLM limits, embeddings & cosine similarity, vector databases, chunking & grounded answers) |
| [6th_week](6th_week/) | Web-Search-Augmented Research (search APIs, relevance re-ranking, grounded research pipelines, tool evaluation) |
| [7th_week](7th_week/) | Agentic AI: ReAct Loops, Local LLMs & Safety (agent frameworks, quantization, guardrails) |
| [8th_week](8th_week/) | LangChain Framework Basics (LCEL, PromptTemplate, tool-using agents, conversational memory) |

This is a companion to a separate portfolio of full-stack products built around these same topics — see [`applied-ai-builds`](https://github.com/ShaunKim91/applied-ai-builds).
